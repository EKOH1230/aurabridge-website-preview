Mode d’emploi

  1. Placer le matelas sur une base adaptée. C’est un matelas, pas un cadre de lit.
  2. Raccorder la pompe et suivre les instructions fournies avec le produit.
  3. Vérifier que le matelas est gonflé comme décrit dans ces instructions.
  4. Nettoyer la housse selon les instructions fournies avec le produit.

Suivre les instructions de nettoyage fournies avec le produit. Ne pas utiliser une méthode qui n’y figure pas.
