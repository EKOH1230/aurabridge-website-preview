# AuraBridge website

An English B2B website for AuraBridge. It introduces the company and shows four products in the range: three beauty devices and one alternating-pressure air mattress.

**View the website:** https://ekoh1230.github.io/aurabridge-website-preview/

## View locally

Open `index.html` in a browser. The site uses plain HTML, CSS, and a small JavaScript file, with no build step or dependencies.

## Pages

- `index.html` — introduction
- `about.html` — purpose and principles
- `partnerships.html` — potential areas for discussion
- `products.html` — four models in the AuraBridge range, beauty devices first and the air mattress last, with locally hosted photos
- `contact.html` — contact placeholder

Shared assets live in `assets/`. Product photo sources are recorded in `docs/product-images.json`. The header mark is `assets/aurabridge-logo.svg`, a bridge icon with the AuraBridge name. The favicon uses the same bridge.

## Content status

The product list is KF-2212, KH-2406, KH-2307 and OB-1600. Beauty devices are presented as the AuraBridge range. The mattress remains an ObboMed product. Photos are stored locally and recorded in `docs/product-images.json`. One KH-2406 photo was left out because its title contains the characters 米诺. Prices are not shown; each card links to a request-a-quote path on the contact page. Certification and treatment claims are not used. No contact form, tracking, payment, or data collection is connected.

Publishing this repository with GitHub Pages makes the site publicly accessible to anyone with the URL. Keep internal source documents out of this repository.
